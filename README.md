# Favorite Artist

## 📌 Опис проєкту

**Favorite Artist** — це односторінковий вебсайт для презентації улюбленого артиста. Проєкт має навчальний та портфоліо-характер і демонструє роботу з версткою, інтерактивними елементами та сторонніми JavaScript-бібліотеками.

### Основні задачі:
- Презентація інформації про артиста
- Відображення контенту у вигляді слайдера
- Інформування користувача через нотифікації

## 🛠 Технології

- **HTML5** — структура сторінки
- **CSS3** — стилізація та адаптивність
- **JavaScript (ES6+)** — логіка взаємодії
- **Swiper.js** — слайдери та каруселі
- **iziToast** — повідомлення та нотифікації
- **Git / GitHub** — контроль версій
- **GitHub Pages** — деплой проєкту

### Локальний запуск

1. Клонувати репозиторій:
   ```bash
   git clone https://github.com/vladyslav-mohyla/Favorite-Artist.git
   ```
   
Перейти в директорію проєкту:

```bash
cd Favorite-Artist
```
Відкрити файл index.html у браузері або скористатися Live Server.
